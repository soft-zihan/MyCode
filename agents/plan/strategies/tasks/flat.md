# Flat Task List

简单的扁平任务列表。

## 流程

1. 读取 `{plan_dir}/spec.md` 了解需求
2. 将需求拆分为独立的任务
3. 每个任务一行，按执行顺序排列
4. 写入 `{plan_dir}/tasks.md`

## tasks.md 格式

```markdown
<!-- TASKS START -->
## 任务清单

- [ ] 1. 任务描述 1
- [ ] 2. 任务描述 2
- [ ] 3. 任务描述 3
<!-- TASKS END -->
```

## 注意事项

- 任务粒度适中，每个任务 15-30 分钟可完成
- 任务之间尽量独立，减少依赖
- 按逻辑顺序排列（先基础后上层）
